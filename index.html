EVAA

The in-house AI that runs locally

EVAA is Umbra-Noesis's in-house AI. It is in active development and in internal use. It is not offered for sale or public download.

EVAA is voice-enabled and runs local AI models on our own hardware. Cloud AI models are optional (your keys, your choice). Features that need the internet (web search, weather, markets, update checks) contact outside services.

Speaks on boot — announces live system status

Installation

Private developer pre-release

The EVE Systems installer is a guided setup, shared only with authorized developers. There is no public download. Install needs the internet. Runs on an existing Linux installation — no OS reinstall needed.
